# Module 6 glossary input

- **Simple effect:** the effect of one variable at a specific value of another variable with which it interacts; in an interaction model, each "main effect" is a simple effect at the reference value of the other variable.
- **Centring:** subtracting a reference value from a variable (for example time minus 12 months, or age minus 60) so that zero, and therefore the intercept and lower-order terms, refers to a meaningful value; the model's fit is unchanged.
- **Reference grid:** the set of covariate combinations (for example every arm at every visit) at which `emmeans` computes model predictions.
- **Estimated marginal mean (EMM):** a model-based mean for a cell of the reference grid, averaged over other covariates in a stated way; in a linear mixed model it is a population-average mean.
- **Contrast:** a linear combination of means with weights that sum to zero, such as a difference in mean change.
- **Difference in mean change:** the mean change from baseline in one group minus the mean change in another; the primary estimand of WALK.
- **Interaction contrast:** a contrast that crosses two sets of contrasts, for example "each visit minus baseline" with "each arm minus control", giving differences in change at every visit.
- **Familywise error rate (FWER):** the probability of at least one false rejection among a family of hypothesis tests.
- **Holm procedure:** a stepwise Bonferroni-type adjustment that tests ordered p-values at α/m, α/(m − 1), and so on; uniformly more powerful than Bonferroni.
- **Dunnett adjustment:** a multiplicity adjustment for comparisons of several groups with a common control that uses the joint distribution of the test statistics.
- **Fixed-sequence (hierarchical) testing:** testing prespecified hypotheses in order, each at the full α, stopping at the first non-rejection.
- **Population-average (marginal) prediction:** a prediction with the random effects set to zero, $\mathbf{x}^\top\hat{\boldsymbol\beta}$; the expected outcome for the population with given covariates.
- **Subject-specific (conditional) prediction:** a prediction that adds a participant's predicted random effects, $\mathbf{x}^\top\hat{\boldsymbol\beta} + \mathbf{z}^\top\hat{\mathbf{b}}_i$.
- **Prediction interval:** an interval expected to contain a single new observation with stated probability; it includes between-participant and residual variation as well as uncertainty about the mean.
- **Confidence interval for a mean trajectory:** an interval for the population mean outcome at each time, reflecting only the uncertainty in the estimated fixed effects.
- **Conditional variance of the BLUPs:** the prediction-error variance of a participant's predicted random effects, used for prediction intervals for participants already observed.
- **Constrained longitudinal data analysis (cLDA):** a model for randomised trials in which all arms share a single mean at the pre-randomisation baseline.
