# Module 8 glossary input

- **Generalized linear mixed model (GLMM):** a generalized linear model whose linear predictor includes random effects, so that observations are independent given each participant's random effects.
- **Subject-specific (conditional) effect:** an effect that compares expected outcomes for the same participant (same random effects) under different covariate values.
- **Laplace approximation:** an approximation to the GLMM likelihood that replaces the integrand over the random effects by a normal curve at its peak; equivalent to adaptive quadrature with one point.
- **Adaptive Gauss-Hermite quadrature (AGQ):** numerical integration of the GLMM likelihood with several nodes centred and scaled at the peak of the integrand; in `glmer` available only for a single scalar random effect (`nAGQ` > 1).
- **Latent-scale ICC:** for a logistic random-intercept model, tau^2 / (tau^2 + pi^2/3), the share of variation in the latent propensity that lies between participants.
- **Attenuation:** the shrinkage of population-average (marginal) logistic coefficients towards zero relative to subject-specific ones, approximately by the factor 1 / sqrt(1 + 0.346 tau^2).
- **Conditional prediction (at b = 0):** the predicted probability or mean for a participant with random effects equal to zero, the median participant for a symmetric random-effects distribution.
- **Population-averaged (marginal) prediction:** the predicted probability or mean averaged over the random-effects distribution; for a logit link obtained by numerical integration, for a log link by multiplying by exp(tau^2/2).
- **Parametric bootstrap:** simulating new datasets from a fitted model, refitting, and using the distribution of the recomputed quantity to form intervals (`lme4::bootMer`).
- **Offset:** a term in the linear predictor with coefficient fixed at 1, such as log(exposure), so that the model describes a rate.
- **Rate ratio:** the ratio of event rates between two conditions; for a log link with a random intercept it is the same for individuals and for the population.
- **Overdispersion:** variance of counts greater than the model implies (for a Poisson model, greater than the mean), even after allowing for random effects.
- **Negative binomial (nbinom2):** a count distribution with variance mu + mu^2/theta, where theta is the size (dispersion) parameter; reduces to Poisson as theta grows.
- **Zero inflation:** more zeros than the count model predicts, attributed to a separate process producing structural zeros; modelled with `ziformula` in glmmTMB.
- **DHARMa scaled residuals:** simulation-based residuals, the position of each observed value within the distribution of values simulated from the fitted model; uniform on 0 to 1 under a correct model.
- **Conditional vs unconditional simulation (DHARMa):** simulating new data with the fitted random effects held fixed (the DHARMa 0.5.0 default, suited to observation-level checks) or with new random effects drawn (needed for checks aggregated by participant).
