# Module 5 glossary input

- **Marginal covariance ($V_i$):** the covariance matrix of a participant's repeated measurements after averaging over the random effects, $V_i = Z_iGZ_i^\top + R_i$.
- **Residual correlation structure:** a rule that specifies the correlation between the residual errors of a participant's measurements, such as compound symmetry, AR(1), exponential or unstructured.
- **Covariance pattern model:** a model with fixed effects and a structured residual covariance but no random effects, fitted for example with `nlme::gls()`.
- **Compound symmetry (CS):** a structure with equal variances and the same correlation between every pair of occasions; implied by a random intercept alone.
- **First-order autoregressive structure, AR(1):** a structure in which the correlation between measurements $k$ positions apart is $\rho^k$.
- **Continuous-time exponential correlation:** correlation $\exp(-|t-s|/\phi)$ that decays with the actual time between measurements; $\phi$ is the range. Equivalent to `corCAR1`.
- **Range ($\phi$):** the time scale of an exponential correlation; the correlated part falls by a factor $e$ over one range.
- **Nugget:** the proportion of the residual variance that is uncorrelated, usually interpreted as measurement error.
- **Unstructured covariance:** a covariance with a separate variance for each occasion and a separate covariance for each pair; $n(n+1)/2$ parameters for $n$ occasions.
- **Serial correlation:** correlation between measurements on the same participant that decreases as the time between them increases.
- **Heterogeneous variances:** residual variances that differ between occasions or groups; modelled with `varIdent()`.
- **Semivariogram:** a plot of half the mean squared difference between pairs of residuals from the same participant against their time separation; flat at 1 for normalized residuals when no correlation remains.
- **Normalized residuals:** residuals transformed by the inverse of the estimated covariance, which should be independent with unit variance if the covariance model is correct.
- **Akaike information criterion (AIC):** $-2\log L + 2p$; smaller values indicate a better balance of fit and complexity.
- **Bayesian information criterion (BIC):** $-2\log L + p\log n$; penalises extra parameters more strongly than AIC in large samples.
- **Boundary problem:** a hypothesis test in which the null value lies on the edge of the parameter space, such as a variance equal to zero; the usual chi-square reference distribution does not apply.
- **Mixture chi-square distribution:** the null distribution of a likelihood-ratio statistic for a boundary hypothesis, for example $\tfrac12\chi^2_0 + \tfrac12\chi^2_1$ for a single variance.
- **Singular fit:** a mixed-model fit in which the estimated random-effects covariance matrix is not of full rank, for example a variance of zero or a correlation of ±1.
- **Convergence warning:** a message that the optimiser stopped without meeting its convergence criteria; it calls for checking the estimates, not for automatic acceptance or rejection.
- **Parsimony:** preferring the simplest model that describes the data adequately for the question at hand.
- **Mixed model for repeated measures (MMRM):** a model with a saturated visit-by-group mean and an unstructured residual covariance, common in clinical trials with a fixed visit schedule.
