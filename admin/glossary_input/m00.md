# Module 0 glossary input

- **R project:** a folder with an `.Rproj` file; opening it sets the working directory to the project root so that relative paths work.
- **Relative path (`here()`):** a file path built from the project root, so that code runs unchanged on any computer.
- **Pipe (`|>`):** passes the result on its left as the first argument of the function on its right.
- **Factor / reference level:** a categorical variable stored with ordered levels; the first level is the reference category against which regression coefficients compare the others.
- **Linear regression:** a model for the mean of a continuous outcome as a linear function of predictors, with independent, constant-variance residuals.
- **Regression coefficient:** the difference in the mean outcome for a one-unit difference in a predictor, holding the other predictors fixed.
- **Intercept:** the mean outcome when all predictors equal zero.
- **Centring:** subtracting a meaningful reference value from a predictor so that zero, and hence the intercept or a main effect, refers to a realistic value.
- **Residual:** the difference between an observed outcome and its fitted value; its standard deviation is the residual standard error.
- **R² (coefficient of determination):** the proportion of the outcome's variance explained by the model.
- **Confidence interval:** a range of values for a parameter that are compatible with the data, constructed so that 95% of such intervals contain the true value over repeated studies.
- **p-value:** the probability of an estimate at least as extreme as the one observed if the true parameter were zero (or another null value).
- **Interaction:** a term that allows the effect of one predictor to depend on the value of another.
- **Main effect (under an interaction):** the effect of a predictor when the other predictor in the interaction equals zero; a conditional effect.
- **Logistic regression:** a model for a binary outcome in which the log-odds of the outcome are linear in the predictors.
- **Odds / odds ratio:** odds are $p/(1-p)$; an odds ratio is the ratio of the odds in two groups, the exponentiated logistic coefficient.
- **Predicted probability:** the probability of the outcome implied by a logistic model for a given covariate profile, obtained with the inverse logit.
- **Calibration:** agreement between predicted probabilities and observed proportions.
- **Residual-versus-fitted plot:** a plot of residuals against fitted values used to check the mean structure and constant variance.
- **Normal Q–Q plot:** a plot of ordered standardised residuals against normal quantiles used to check normality of the residuals.
- **Homoscedasticity:** constant residual variance across fitted values.
- **Prediction interval:** a range within which a new individual observation is expected to fall; it adds the residual variance to the uncertainty about the mean.
- **Independence assumption:** the assumption that residuals of different observations are unrelated; violated by repeated measurements on the same subject.
