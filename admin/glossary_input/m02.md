# Module 2 glossary input

- **Long format:** a data layout with one row per observation (participant and measurement occasion), with columns for the identifier, time and outcome. Required by mixed models, GEE and most longitudinal plots.
- **Wide format:** a data layout with one row per participant and one column per scheduled visit for each repeated variable. It can hold only the scheduled time, not each participant's actual time.
- **Key (subject–visit key):** the combination of variables, here participant identifier and visit, that must identify exactly one row in a long dataset.
- **Reshaping (pivoting):** converting between long and wide formats, in R with `tidyr::pivot_longer()` and `tidyr::pivot_wider()`.
- **Many-to-one join:** a join in which many rows of one file (visits) match exactly one row of another (participants). In `dplyr` it is checked with `relationship = "many-to-one"`.
- **Anti-join:** a join that returns the rows of one file that have no match in another; used to find unmatched identifiers.
- **Exact duplicate:** a record identical in every field to another record, after formatting has been standardised. One copy is removed.
- **Conflicting duplicate:** two or more different records for the same participant and visit. Resolved by querying the source or by a rule fixed in advance, and flagged.
- **Data query:** a documented request to a study site to confirm or correct a questionable value.
- **Cleaning log:** a table recording each cleaning step and the number of records affected, so that the analysis file can be reproduced and audited.
- **Plausibility (range) check:** a check that values lie within limits fixed in advance; values outside are treated as errors and queried.
- **Scheduled time:** the time at which a visit was planned by the protocol (`month_sched` in WALK).
- **Actual time:** the time at which the measurement was actually taken, here months since randomisation calculated from dates (`month` in WALK).
- **Visit window:** the protocol's permitted range around a scheduled visit date. Visits outside it are out-of-window visits.
- **Complete visit grid:** every randomised participant crossed with every scheduled visit, built from the design, used to reveal and classify missing visits.
- **Intermittent missingness:** a missed visit followed by at least one later attended visit.
- **Dropout:** permanent loss to follow-up after some visit, giving a monotone missing-data pattern. In WALK, a participant whose last attended visit is before month 12.
- **Participant-flow table:** a table of the number (and percentage of those randomised) of participants seen at each scheduled visit, by group.
- **Spaghetti plot:** a plot with one line per participant showing the outcome over time.
- **Individual trajectory panels:** small separate plots of the outcome over time for selected participants.
- **Missingness map:** a tile plot of participants (rows) by scheduled visits (columns) showing which measurements are observed.
- **Pattern plot (dropout-pattern plot):** mean outcome profiles plotted separately for groups of participants defined by the time of their last attended visit.
- **Observed mean:** the mean outcome at a visit among participants measured at that visit; it estimates E(Y | observed), which differs from the mean of all randomised participants when missingness depends on the outcome history.
