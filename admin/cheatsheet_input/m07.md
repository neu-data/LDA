# Module 7 cheat-sheet input: generalized estimating equations

## GEE (marginal model with robust standard errors)

- **Purpose:** estimate population-average (marginal) effects for continuous, binary or count outcomes, treating within-participant correlation as a nuisance.
- **Key assumptions:** correct mean model (link, covariates, form of time); independent clusters; many clusters; missing data MCAR (or depending only on covariates in the mean model).
- **R example:**
  ```r
  clear <- load_clear() |> arrange(id, week)          # clusters contiguous
  fit <- geeglm(itch ~ week * arm, id = factor(id),    # never a character id
                waves = visit, data = clear,
                family = binomial, corstr = "exchangeable")
  summary(fit)                                         # robust (sandwich) SEs
  emmeans(fit, ~ arm | week, at = list(week = 12), type = "response")
  ```
- **Report:** link and mean model, working correlation, number of clusters, robust SE; effects on the response scale (odds/rate ratios plus predicted proportions, risk differences or expected counts).
- **Common error:** `id = id` with character identifiers: "NAs introduced by coercion", the whole dataset becomes one cluster and SEs are meaningless. Use `factor(id)` and sort by id and time.

## Working correlation

- **Purpose:** weight observations within a cluster to gain efficiency.
- **Key assumptions:** none for consistency (only the mean model must be right); efficiency improves the closer it is to the truth.
- **R example:**
  ```r
  for (s in c("independence", "exchangeable", "ar1"))
    print(coef(geeglm(sbp ~ visit_f * arm, id = factor(id), waves = visit,
                      data = walk, corstr = s))["visit_f12:armEP"])
  QIC(fit)          # exists in geepack 1.3.13; weak guide for correlation
  ```
- **Report:** prespecified structure and the estimated correlation parameter (as a nuisance).
- **Common error:** choosing the structure by QIC or by the smallest p-value. Note: geepack 1.3.13 crashes R with `corstr = "unstructured"` plus `waves` on incomplete clusters.

## Model-based vs robust (sandwich) SE, and small-sample correction

- **Purpose:** valid inference whatever the true correlation (sandwich); bias correction when clusters are few (Mancl-DeRouen).
- **Key assumptions:** sandwich needs many clusters (roughly 40-50 or more); model-based SE needs a correct working covariance.
- **R example:**
  ```r
  sqrt(diag(vcov(fit)))                 # sandwich
  sqrt(diag(fit$geese$vbeta.naiv))      # model-based
  # Mancl-DeRouen: sandwich_gee(fit, "MD") defined in notes/07-gee.qmd
  ```
- **Report:** which SE; with few clusters, the corrected SE and a t reference distribution (N - p df).
- **Common error:** trusting the uncorrected sandwich with 10-20 clusters (coverage about 0.91 with 10 clusters in the module simulation).

## Inverse-probability-weighted GEE (advanced)

- **Purpose:** population-average analysis when dropout depends on observed outcomes (MAR).
- **Key assumptions:** correctly specified dropout model; positivity (no near-zero probabilities of remaining); independence working correlation.
- **R example:**
  ```r
  drop_model <- glm(stay ~ prev_sev + arm, family = binomial, data = risk)
  # ipw = 1 / cumulative product of fitted P(stay) up to each visit
  geeglm(itch ~ week * arm, id = factor(id), data = clear_w,
         family = binomial, corstr = "independence", weights = ipw)
  ```
- **Report:** dropout model, range of weights, weighted estimates; state that SEs ignore weight estimation.
- **Common error:** observation-level weights with an exchangeable working correlation.

## Decision points (for method-selection diagrams)

- Question about population averages (proportions, mean counts) and outcome non-normal: GEE (or GLMM with marginalisation). Question about within-person change or individual prediction: GLMM.
- Continuous outcome, identity link: GEE and LMM estimate the same fixed effects; prefer LMM under MAR dropout.
- Fewer than about 40-50 clusters: bias-corrected sandwich and t reference, or a mixed model with a credible covariance.
- Dropout depends on observed outcomes: not standard GEE; use a likelihood method or IPW-GEE.
- Time-varying covariates possibly affected by past outcomes: independence working correlation.
