# Module 9 cheat-sheet input: time-varying predictors and nonlinear change

## Person-mean centring (within- and between-person effects)

- **Purpose:** separate the association of a time-varying covariate with the outcome into a within-person part (deviations from the person's own mean) and a between-person part (differences in person means).
- **Key assumptions:** usual mixed-model assumptions; linear association at each level; between-person part needs adjustment for between-person confounders; neither part is causal without further assumptions.
- **R example:**
  ```r
  walk <- walk |> group_by(id) |> mutate(steps_pm = mean(steps)) |> ungroup() |>
    mutate(steps_wc = steps - steps_pm,
           steps_gm = steps_pm - mean(steps_pm[!duplicated(id)]))
  m <- lmer(sbp ~ steps_wc + steps_gm + visit_f * arm + age10 + sex + bmi_c +
              (1 + month | id), data = walk, control = lmer_ctrl)
  ```
- **Report:** within-person and between-person coefficients with 95% CIs (per stated unit), and the contextual effect (between minus within) if the difference matters.
- **Common error:** reporting one coefficient for a time-varying covariate; it blends two different questions.

## Adjusting a treatment effect for a time-varying covariate

- **Purpose:** decide whether a post-randomisation covariate belongs in the model.
- **Key assumptions:** if the covariate is affected by treatment (a mediator), adjusting for it changes the estimand from the total effect to a direct effect, which is no longer protected by randomisation.
- **R example:**
  ```r
  m_total  <- lmer(sbp ~ visit_f * arm + (1 + month | id), data = walk)
  m_direct <- lmer(sbp ~ steps_wc + visit_f * arm + (1 + month | id), data = walk)
  ```
- **Report:** the total effect as the primary result; any mediator-adjusted estimate as a labelled secondary analysis.
- **Common error:** adjusting the primary trial comparison for post-randomisation variables "to gain precision".

## Actual time for unequal intervals

- **Purpose:** estimate rates of change correctly when visits are unequally spaced or irregular.
- **Key assumptions:** visit timing carries no information about the outcome beyond the model (otherwise see Module 10, informative visit timing).
- **R example:**
  ```r
  lmer(sbp ~ month * arm + (1 + month | id), data = walk, control = lmer_ctrl)
  lmer(egfr ~ years + (1 + years | id), data = kidney, control = lmer_ctrl)
  ```
- **Report:** the time unit, how time was measured (from dates), and slopes per unit time.
- **Common error:** using visit number as time.

## Polynomial, piecewise linear and natural spline trajectories

- **Purpose:** describe curved mean trajectories within a linear mixed model.
- **Key assumptions:** the chosen family of curves approximates the true shape; knots chosen in advance; compare fixed-effect structures with ML.
- **R example:**
  ```r
  walk$month_p3 <- pmax(walk$month - 3, 0)
  m_pw <- lmer(sbp ~ (month + month_p3) * arm + (1 + month | id), data = walk, REML = FALSE)
  m_ns <- lmer(sbp ~ splines::ns(month, df = 3) * arm + (1 + month | id), data = walk, REML = FALSE)
  AIC(m_pw, m_ns); BIC(m_pw, m_ns)
  ```
- **Report:** phase-specific slopes (piecewise) or fitted curves with intervals (splines); contrasts at stated times computed from predictions.
- **Common error:** interpreting individual spline coefficients, or extrapolating a polynomial.

## Generalized additive mixed model (mgcv)

- **Purpose:** estimate smooth trajectories with data-driven smoothness.
- **Key assumptions:** smooth true curve; basis dimension `k` large enough (`gam.check()`); usual mixed-model assumptions. Smooths are centred, so parametric group terms are average differences.
- **R example:**
  ```r
  g <- gamm(sbp ~ arm + s(month, by = arm, k = 5),
            random = list(id = ~ 1 + month), data = walk, method = "REML")
  summary(g$gam); plot(g$gam, pages = 1)
  # same model, random-effect smooths: bam(... + s(idf, bs = "re") + s(idf, month, bs = "re"))
  ```
- **Report:** edf of each smooth, fitted curves with 95% intervals, estimands derived from predictions (lpmatrix).
- **Common error:** using `gam()` with hundreds of `bs = "re"` levels (very slow; use `gamm()` or `bam()`), or a character id with `bs = "re"`.

## Decision points (for method-selection diagrams)

- Time-varying covariate? Yes: decompose into within and between parts. Is it affected by treatment? Yes: do not adjust the primary treatment effect for it.
- Visits unequally spaced or irregular? Use actual time; never visit number. Common scheduled visits and a visit-specific estimand: categorical time for the mean, actual time in the random part.
- Shape of change: natural break known in advance: piecewise linear. Smooth curve: natural spline or GAMM. Need a rate parameter with physical meaning: nonlinear mixed model (Module 13).
- Causal question about a time-varying exposure: standard regression is not enough; marginal structural models (Module 13).
