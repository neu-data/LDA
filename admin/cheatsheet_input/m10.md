# Module 10 cheat-sheet input: missing data and dropout

## Describing missingness

- **Purpose:** classify missing data (intermittent, dropout, missing covariates) and see whether dropout relates to observed data.
- **Key assumptions:** a complete grid of scheduled visits is available; the observed flag is correct.
- **R example:**
  ```r
  visit_flow(walk, id, month_sched, arm)
  plot_missing_map(grid, id, month_sched, observed, order_by = as.numeric(observed) * visit)
  glm(drop_now ~ prev_sbp10 + arm, family = binomial, data = risk)   # discrete-time dropout
  ```
- **Report:** numbers and percentages with complete data, intermittent gaps and dropout by arm; reasons for dropout; association of dropout with observed outcomes.
- **Common error:** claiming a test showed the data are MAR (data can only show evidence against MCAR).

## Likelihood-based mixed model of all observed data (primary analysis under MAR)

- **Purpose:** valid estimation of the mean trajectory and treatment contrasts when data are MAR.
- **Key assumptions:** MAR; separability of outcome and missingness parameters (ignorability); correct mean and covariance model; variables that drive dropout in the model.
- **R example:**
  ```r
  m <- lmer(sbp ~ visit_f * arm + (1 + month | id), data = walk, control = lmer_ctrl)
  e <- emmeans(m, ~ visit_f | arm, at = list(visit_f = c("0", "12")))
  ch <- contrast(e, list(change = c(-1, 1)), by = "arm")
  summary(contrast(ch, "trt.vs.ctrl", by = NULL), infer = TRUE, adjust = "none")
  ```
- **Report:** the MAR assumption and why it is plausible; estimates with CIs; sensitivity analysis.
- **Common error:** fitting the model to completers only, or using LOCF.

## Multiple imputation (wide format by arm; long format multilevel)

- **Purpose:** MAR-based inference with an analysis model that cannot handle missing data, with auxiliary variables, or as the basis for delta adjustment.
- **Key assumptions:** MAR; imputation model congenial with the analysis model (includes arm and its interaction with visit); enough imputations.
- **R example:**
  ```r
  imp <- mice(filter(walk_w, arm == "EP")[, vars], m = 50, method = "norm", seed = 1)
  # long: meth["sbp"] <- "2l.norm"; pred: cluster -2, fixed 1, random 2
  p <- mice::pool.scalar(Q = est, U = se^2, n = 360, k = 3)   # Rubin's rules
  c(p$qbar, sqrt(p$t), p$df, p$fmi)
  ```
- **Report:** imputation model (variables, method, by arm), number of imputations, pooled estimates with CIs, fraction of missing information.
- **Common error:** imputing without arm, or averaging the completed data sets before analysis.

## Delta adjustment and tipping point

- **Purpose:** examine how conclusions change if dropouts' outcomes differ from the MAR prediction by δ.
- **Key assumptions:** a clinically justified choice of which values are shifted (for example post-dropout values in active arms) and of the δ range, specified in advance.
- **R example:**
  ```r
  d$sbp_m12 <- d$sbp_m12 + ifelse(d$arm != "UC" & d$last_month_sched < 12, delta, 0)
  tip <- bind_rows(lapply(seq(0, 30, 2), delta_fit))   # re-analyse and pool per delta
  ```
- **Report:** the δ grid and its rationale, estimates with CIs across δ (tipping-point plot), the tipping point and whether it is plausible.
- **Common error:** presenting the analysis as a test of MAR, or choosing the δ grid after seeing the results.

## LOCF (not recommended)

- **Purpose:** none as a primary analysis; shown to explain why it fails.
- **Key assumptions:** no change after dropout, which is rarely plausible; biased even under MCAR when trajectories change over time; understates uncertainty.
- **Common error:** calling LOCF conservative.

## Informative visit timing

- **Purpose:** recognise when visit frequency depends on the outcome and choose a suitable analysis.
- **Key assumptions:** a mixed model is protected if visit timing depends only on observed past outcomes and the model is correct.
- **R example:**
  ```r
  kidney |> group_by(low = egfr < 30) |> summarise(gap = mean(next_gap, na.rm = TRUE))
  lmer(egfr ~ years + I(years^2) + diabetes * years + age10 + (1 + years | id), data = kidney)
  ```
- **Report:** evidence that the visit process depends on the outcome; model-based means rather than window averages.
- **Common error:** averaging all measurements in time windows.

## Decision points (for method-selection diagrams)

- Is dropout related to observed outcomes? Yes: not MCAR; avoid completers-only and observed means.
- Primary analysis: likelihood-based mixed model (continuous: LMM; non-Gaussian: GLMM) under MAR. GEE: needs weighting under MAR (Module 7).
- Need auxiliary post-baseline variables, an ANCOVA-type analysis, or missing covariates? Use MI respecting arm and visit structure.
- Always add a sensitivity analysis for MNAR (delta adjustment / tipping point).
- Visits driven by the outcome? Do not average by time window; model the patient's trajectory; consider joint models (Module 13).
