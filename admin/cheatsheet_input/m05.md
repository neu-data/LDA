# Module 5 cheat-sheet input: modelling covariance and choosing a model

## Residual correlation structures with `gls()` (CS, AR(1), exponential, unstructured)

- **Purpose:** describe the within-participant correlation directly, without random effects, so that standard errors of within-person contrasts are correct and likelihood inference is valid under MAR.
- **Key assumptions:** correct mean model; normal residuals; the same covariance pattern for every participant. CS: equal correlation at all lags. AR(1): correlation rho^k for visits k steps apart (integer index). Exponential: (1 - nugget) exp(-|dt|/range) in actual time. Unstructured: needs a common visit schedule; 21 parameters for 6 visits.
- **R example:**
  ```r
  gls(sbp ~ visit_f * arm, data = walk, correlation = corCompSymm(form = ~ 1 | id))
  gls(sbp ~ visit_f * arm, data = walk, correlation = corAR1(form = ~ visit | id))
  gls(sbp ~ visit_f * arm, data = walk, correlation = corExp(form = ~ month | id, nugget = TRUE))
  gls(sbp ~ visit_f * arm, data = walk, correlation = corSymm(form = ~ visit | id),
      weights = varIdent(form = ~ 1 | visit_f))
  ```
- **Report:** the structure and why it was chosen, its parameters (e.g. range and nugget), implied correlation at short and long lags, estimation by REML.
- **Common error:** `corAR1(form = ~ month | id)` with non-integer times, or `corSymm(form = ~ 1 | id)` without a visit index when visits are missed.

## Heterogeneous residual variances (`varIdent`)

- **Purpose:** allow the residual SD to differ by visit (or arm).
- **Key assumptions:** ratios common to all participants; correlation structure as specified separately.
- **R example:**
  ```r
  m_het <- update(m_cs, weights = varIdent(form = ~ 1 | visit_f))
  coef(m_het$modelStruct$varStruct, unconstrained = FALSE, allCoef = TRUE)
  anova(m_cs, m_het)        # REML LRT, same fixed effects
  ```
- **Report:** SD ratios relative to the reference visit and the LRT; in WALK ratios were 1.00 to 1.04, p = 0.76, so a common variance was kept.
- **Common error:** `weights = ~ visit_f` (that is `varFixed`), or reading `sigma` as a common SD when it is the reference-level SD.

## Random effects plus serial correlation: the marginal covariance

- **Purpose:** combine a stable person-level component (random intercept, slope) with short-term serial correlation and measurement error; compute V_i = Z_i G Z_i' + R_i and compare it with the observed covariance.
- **Key assumptions:** random effects and residuals normal and independent of each other; components can be hard to separate with few visits.
- **R example:**
  ```r
  m <- lme(sbp ~ visit_f * arm, random = ~ 1 + month | id, data = walk,
           correlation = corExp(form = ~ month | id, nugget = TRUE))
  G <- as.matrix(getVarCov(m)); Z <- cbind(1, c(0, 1, 3, 6, 9, 12))
  V <- Z %*% G %*% t(Z) + R    # R = sigma^2 * correlation matrix at the same times
  Variogram(m_rs, form = ~ month | id, resType = "normalized")   # check
  ```
- **Report:** SDs of intercept and slope, residual SD, range and nugget, implied versus observed correlation (e.g. baseline to month 12).
- **Common error:** interpreting the random-slope SD substantively when serial correlation is not modelled (in WALK it rises from 0.34 to 0.54 mmHg/month); trying to fit `correlation =` in `lmer()`.

## Comparing covariance models: LRT, AIC, BIC, REML vs ML

- **Purpose:** choose an adequate covariance model and compare mean models correctly.
- **Key assumptions:** same observations in every model; REML only when fixed effects are identical; LRT only for nested models.
- **R example:**
  ```r
  AIC(m_cs, m_exp, m_un); BIC(m_cs, m_exp, m_un)     # REML, same mean model
  anova(m_ri, m_ri_exp)                              # nested, REML
  anova(m_lin, m_prim)                               # lmer: refits by ML automatically
  anova(update(g1, method = "ML"), update(g2, method = "ML"))   # gls, different means
  ```
- **Report:** the candidate set, information criteria, the chosen model and why; ML for fixed-effect comparisons.
- **Common error:** comparing REML log-likelihoods across different fixed effects (rescaling time from months to weeks alone changes REML logLik by 4.4 in WALK).

## Boundary tests, singular fits and convergence

- **Purpose:** test whether a variance component is needed and respond sensibly to boundary estimates.
- **Key assumptions:** asymptotic mixture distributions; other parameters interior.
- **R example:**
  ```r
  lt <- lr_test(m_prim, m_clinic)                 # adds (1 | clinic)
  p_boundary_mixture(lt$chisq)                    # 0.5 chi2(0) + 0.5 chi2(1)
  p_boundary_mixture(chisq, df_mix = c(1, 2))     # random slope added to intercept
  isSingular(m); VarCorr(m)
  ```
- **Report:** LR statistic and mixture p-value; any singular fit, which component was on the boundary, what was done, and whether the estimand changed.
- **Common error:** naive chi-square p-values (too large); treating a singular fit as proof that a variance is zero; silencing convergence warnings without comparing optimisers.

## Decision points (for method-selection diagrams)

- Visits on a common schedule and enough participants per visit? Unstructured (MMRM) is a common prespecified choice. Irregular times? Random intercept and slope and/or exponential serial correlation in actual time.
- Observed correlation declines with lag but levels off? Random intercept plus serial correlation (exponential with nugget).
- Comparing covariance structures with the same mean: REML + AIC/BIC (+ LRT if nested). Comparing mean models: ML.
- Testing a variance = 0: use the mixture chi-square.
- Singular fit: identify the component, simplify, check the estimand is unchanged.
- Final choice: prespecified, adequate on checks, sensitivity analyses with alternative structures; the treatment estimate is usually insensitive among reasonable models.
