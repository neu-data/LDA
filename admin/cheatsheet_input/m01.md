# Module 1. Foundations of longitudinal data (cheat sheet input)

## Describing the structure of longitudinal data

- **Purpose:** identify subjects, observations, visits and measurement occasions; assess balance, timing and follow-up before modelling.
- **Key assumptions:** long format (one row per observation) with a subject identifier and a time variable; scheduled time (`month_sched`) kept separate from actual time (`month`).
- **R example:**
  ```r
  check_long(walk, id, month_sched, "sbp")
  walk |> count(id, name = "n_obs") |> count(n_obs)
  visit_flow(walk, id, month_sched, arm)
  ```
- **Report:** number of subjects and observations, distribution of observations per subject, numbers seen at each visit by group, spread of actual around scheduled times.
- **Common error:** treating the number of rows as the sample size; the independent unit is the subject.

## Within-subject dependence and variance components (random-intercept model)

- **Purpose:** quantify how much variation lies between subjects ($\tau_0^2$) and within subjects ($\sigma^2$); ICC $= \tau_0^2/(\tau_0^2 + \sigma^2)$.
- **Key assumptions:** normal random intercepts and residuals; independent subjects; equal correlation for every pair of occasions (compound symmetry), which is usually only approximate.
- **R example:**
  ```r
  round(visit_correlation(walk, id, month_sched, sbp), 2)
  m_ri <- lmer(sbp ~ visit_f * arm + (1 | id), data = walk, control = lmer_ctrl)
  VarCorr(m_ri); icc_lmer(m_ri)
  ```
- **Report:** observed correlation range across visits; between- and within-subject SDs in outcome units; ICC and the fixed effects it is conditional on. (WALK: SDs about 12.0 and 6.2 mmHg, ICC about 0.79.)
- **Common error:** computing the ICC without adjusting for changes in the mean over time and between groups.

## Estimands for longitudinal questions

- **Purpose:** state the target before choosing the model.
- **Key assumptions:** define the population, the times, the contrast and how dropout is handled.
- **R example:**
  ```r
  m <- lmer(sbp ~ visit_f * arm + (1 + month | id), data = walk, control = lmer_ctrl)
  fixef_table(m) |> filter(term == "visit_f12:armEP")   # difference in mean change
  ```
- **Report:** change: $\mu_g(12) - \mu_g(0)$; group difference in change: $[\mu_{EP}(12) - \mu_{EP}(0)] - [\mu_{UC}(12) - \mu_{UC}(0)]$; individual trajectories: $\tau_1^2$ or a predicted individual slope.
- **Common error:** reporting the within-arm change, or "significant in one arm, not the other", as the treatment effect.

## Consequences of ignoring the dependence

- **Purpose:** explain why OLS on repeated measurements is misleading.
- **Key assumptions:** direction of error depends on the comparison.
- **R example:**
  ```r
  lm(sbp ~ month * arm, data = walk)                                     # naive
  lmer(sbp ~ month * arm + (1 + month | id), data = walk, control = lmer_ctrl)
  ```
- **Report:** between-subject comparisons: OLS SE too small (design effect about $1 + (m-1)\rho_I$); within-subject comparisons: OLS SE usually too large (factor about $1/\sqrt{1-\rho_I}$). Simulation (scenario A, 1,000 replicates): OLS SE about 48% of the true SD for the arm difference, coverage about 65%; about 2.1 times the true SD for the time slope.
- **Common error:** assuming ignoring correlation always makes SEs too small.

## Decision points

- Is each unit measured more than once? No: cross-sectional or clustered. Yes: repeated measures; if time order matters, longitudinal.
- Balanced and complete data at common occasions? Classical methods are possible (Module 3); otherwise use mixed models or GEE (Modules 4–8).
- Irregular actual times? Use actual time as continuous; consider continuous-time correlation (Module 5).
- Visit timing depends on the outcome (KIDNEY)? Standard models may be biased; see Modules 10 and 13.
- Large slope variation between subjects? Include a random slope; do not assume the naive SE for slope comparisons is conservative.
