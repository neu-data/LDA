# Module 11 cheat-sheet input: diagnostics and troubleshooting

## Residual diagnostics for a linear mixed model

- **Purpose:** check the mean model, the covariance model, the residual variance and normality.
- **Key assumptions checked:** correct mean trend; adequate covariance; constant residual variance; roughly normal residual errors.
- **R example:**
  ```r
  m <- lmer(sbp ~ visit_f * arm + (1 + month | id), data = walk, control = lmer_ctrl)
  r_cond <- resid(m, scaled = TRUE)                 # y - X beta - Z b, / sigma
  r_marg <- walk$sbp - predict(m, re.form = NA)     # y - X beta
  plot(fitted(m), r_cond); qqnorm(r_cond)
  # Cholesky-scaled marginal residuals: L_i^{-1} r_i with V_i = Z G Z' + sigma^2 I
  ```
- **Report:** which plots were examined, any pattern found and its effect on the estimate.
- **Common error:** using conditional residuals to judge serial correlation (they are negatively correlated within a participant by construction).

## Influence of participants (leave one participant out)

- **Purpose:** find participants whose removal materially changes the reported estimate.
- **Key assumptions:** the participant is the unit of influence; no fixed cut-off.
- **R example:**
  ```r
  m_g <- lmer(sbp ~ visit_f * arm + (1 + month | id), data = walk[walk$id != g, ],
              control = lmer_ctrl, start = getME(m, "theta"))
  dfbeta <- fixef(m)["visit_f12:armEP"] - fixef(m_g)["visit_f12:armEP"]
  ```
- **Report:** range of the estimate over omissions; largest shift as a fraction of the SE.
- **Common error:** deleting influential participants from the primary analysis instead of checking the data and reporting a sensitivity analysis.

## Random-effects checks

- **Purpose:** look for gross departures (outlying participants, strong skew) in the random effects.
- **Key assumptions:** BLUPs are shrunk by tau^2 / (tau^2 + sigma^2 / n_i), so their plots are weak evidence.
- **R example:**
  ```r
  re <- ranef(m)$id
  qqnorm(re[, 1]); qqnorm(re[, 2])
  ```
- **Report:** that plots showed no gross departures, with the shrinkage caveat.
- **Common error:** concluding normality from a straight BLUP Q–Q plot, or changing the fixed-effects model because of it (fixed effects are robust to non-normal random effects).

## Simulation-based (DHARMa) residuals for GLMMs

- **Purpose:** check distribution, dispersion and zeros for binary and count GLMMs on a common uniform scale.
- **Key assumptions:** residuals are uniform on (0, 1) if the model is correct.
- **R example:**
  ```r
  s <- simulateResiduals(m_nb, n = 1000, seed = 1)
  plot(s); testDispersion(s); testZeroInflation(s)
  s_u <- simulateResiduals(m_nb, n = 1000, simulateREs = "unconditional")
  testDispersion(recalculateResiduals(s_u, group = diary$id))
  ```
- **Report:** dispersion ratio, zero ratio and the model chosen as a result.
- **Common error:** adding zero inflation before checking overdispersion; using conditional simulations (DHARMa 0.5.0 default) for participant-level tests.

## GEE mean-model check

- **Purpose:** check that the marginal mean model fits over time in each group.
- **Key assumptions:** GEE validity depends on the mean model (and MCAR for unweighted GEE), not on the working correlation.
- **R example:**
  ```r
  g <- geeglm(itch ~ week * arm, id = id_f, family = binomial, corstr = "exchangeable", data = d)
  d$fit <- fitted(g)[, 1]
  d |> group_by(arm, week) |> summarise(obs = mean(itch), fit = mean(fit))
  QIC(g)
  ```
- **Report:** largest discrepancy between fitted and observed means; QIC compared with a flexible mean model.
- **Common error:** checking normality of GEE residuals.

## Convergence warnings, singular fits, separation

- **Purpose:** decide whether reported estimates are the maximum-likelihood estimates of the specified model.
- **Key steps:** look at estimates; rescale; check the gradient; `allFit()`; simplify in a pre-specified order; adaptive quadrature for binary GLMMs; penalised likelihood under separation.
- **R example:**
  ```r
  m2 <- lmer(sbp ~ visit_f * arm + (1 + month | id), data = walk,
             control = lmerControl(optimizer = "bobyqa"))   # write control out in full
  summary(allFit(m2))$llik; isSingular(m2)
  glmer(itch ~ week * arm + (1 | id), family = binomial, data = clear, nAGQ = 25)
  ```
- **Report:** the warning, what was checked, and that estimates agreed (or what was changed).
- **Common error:** silencing warnings by loosening tolerances; reporting a huge coefficient from a separated model.

## Decision points (for the method-selection diagrams)

- Pattern in marginal residuals over time? Yes: revise the time model for all arms (categorical time or splines). No: continue.
- Remaining correlation in Cholesky-scaled residuals? Yes: add a residual correlation structure as a sensitivity analysis (Module 5).
- Count outcome overdispersed in DHARMa? Yes: negative binomial. Then check zeros; zero inflation only if zeros are still in excess.
- Participant-level DHARMa check? Use `simulateREs = "unconditional"`.
- Convergence warning? Rescale, then `allFit()`. All optimisers agree: keep and log. Disagree or singular: simplify in the pre-specified order.
- Binary GLMM with one random intercept? Compare Laplace with `nAGQ` 10 to 25.
- Zero cells or huge coefficients with huge SEs in logistic models? Separation: report the table and use Firth or a weakly informative prior.
- Any change of model: record it in the analysis log with its status and its effect on the primary estimate.
