# Module 0. Foundations refresher: R and regression (cheat sheet input)

## R project workflow

- **Purpose:** run every script and document from the project root with relative paths.
- **Key assumptions:** the course project (`LDA_course.Rproj`) is open; files are referred to by their place in the project.
- **R example:**
  ```r
  source(here::here("R", "setup.R"))
  walk_base <- load_walk("baseline") |>
    mutate(age10 = (age - 60) / 10, bmi_c = bmi - 29)
  walk_base |> group_by(arm) |> summarise(n = n(), mean_sbp0 = mean(sbp0))
  ```
- **Report:** not applicable (workflow).
- **Common error:** `setwd("C:/Users/...")` in a script; it breaks on every other computer.

## Linear regression

- **Purpose:** model the mean of a continuous outcome as a linear function of predictors; each coefficient is an adjusted difference in means in outcome units.
- **Key assumptions:** correct mean structure (linearity), independent observations, constant residual variance, normal residuals (mainly for small samples and prediction intervals).
- **R example:**
  ```r
  m <- lm(sbp0 ~ age10 + sex + bmi_c, data = walk_base)
  summary(m); confint(m)
  relevel(walk_base$arm, ref = "EP")   # change reference level
  ```
- **Report:** each estimate with 95% CI and units, what it is adjusted for, p-value, residual SD, R².
- **Common error:** interpreting the intercept of an uncentred model (age 0, BMI 0).

## Interaction between a continuous and a categorical predictor

- **Purpose:** let the slope of a continuous predictor differ between groups (the cross-sectional analogue of arm-by-time).
- **Key assumptions:** as linear regression; linear within each group.
- **R example:**
  ```r
  m_int <- lm(sbp0 ~ age10 * sex + bmi_c, data = walk_base)
  emtrends(m_int, ~ sex, var = "age10")   # slope in each group
  ```
- **Report:** group-specific slopes and the difference in slopes with 95% CI; main effects stated as conditional ("sex difference at age 60").
- **Common error:** calling a main effect under an interaction "the effect of sex"; it is the effect where the other predictor is zero, so centre that predictor.

## Logistic regression

- **Purpose:** model the log-odds of a binary outcome; exponentiated coefficients are odds ratios.
- **Key assumptions:** independent observations, log-odds linear in continuous predictors, enough events per parameter.
- **R example:**
  ```r
  g <- glm(hyp150 ~ age10 + sex + bmi_c, family = binomial, data = walk_base)
  exp(cbind(OR = coef(g), confint(g)))
  lp <- predict(g, newdata = nd, type = "link", se.fit = TRUE)
  plogis(lp$fit + c(-1.96, 1.96) * lp$se.fit)   # CI for a probability
  ```
- **Report:** odds ratios with 95% CI, and predicted probabilities with CI for meaningful profiles.
- **Common error:** describing an odds ratio of 0.67 as "33% lower risk".

## Residual checks

- **Purpose:** residual-versus-fitted plot checks the mean structure and constant variance; normal Q–Q plot checks normality of residuals.
- **Key assumptions:** neither plot checks independence, which is judged from the design.
- **R example:**
  ```r
  plot(m, which = 1:2)
  ```
- **Report:** a sentence stating that the checks showed no important departures (or what was found).
- **Common error:** using Q–Q or residual-versus-fitted plots for a binary outcome; use calibration or simulation-based residuals.

## Confidence interval vs prediction interval

- **Purpose:** CI for the mean outcome of people with given covariates; PI for one new person's outcome.
- **Key assumptions:** PI relies on normal residuals with constant variance.
- **R example:**
  ```r
  predict(m, newdata = nd, interval = "confidence")
  predict(m, newdata = nd, interval = "prediction")
  ```
- **Report:** which interval is given and for what question.
- **Common error:** using a CI to describe where individual patients will lie.

## Decision points

- Continuous outcome, one row per subject: linear regression. Binary outcome: logistic regression.
- Question about whether a slope differs between groups: include the interaction and centre the continuous predictor.
- Question about the average: confidence interval. Question about an individual: prediction interval.
- More than one row per subject (repeated measures): ordinary regression is not appropriate; go to Module 1.
