# Module 3 cheat-sheet input: traditional approaches

## Regression with an arm-by-time interaction (OLS, for interpretation only)

- **Purpose:** describe how mean outcome changes with time in each group; the interaction gives the difference in slopes.
- **Key assumptions:** linear mean in time, constant variance, normal residuals, independent residuals (violated by repeated measurements, so standard errors are invalid).
- **R example:**
  ```r
  m <- lm(sbp ~ month * arm, data = walk)
  summary(m); confint(m)
  walk$res <- resid(m)
  visit_correlation(walk, id, month_sched, res)   # check within-person correlation
  ```
- **Report:** slope difference (`month:armEP`) with CI, noting that OLS SEs ignore correlation; use as a teaching step, not a primary analysis.
- **Common error:** reading the arm main effect (`armEP`) as the treatment effect; with an interaction it is the difference at time 0.

## Paired t-test (baseline vs follow-up within a group)

- **Purpose:** estimate mean within-person change in one group.
- **Key assumptions:** independent participants; approximately normal differences; complete pairs representative of the group.
- **R example:**
  ```r
  ep <- wide |> filter(arm == "EP", !is.na(sbp_m0), !is.na(sbp_m12))
  t.test(ep$sbp_m12, ep$sbp_m0, paired = TRUE)
  ```
- **Report:** n pairs, mean change (follow-up minus baseline) with 95% CI.
- **Common error:** claiming a treatment effect from a within-arm test, or comparing p-values between arms.

## Repeated-measures ANOVA (complete cases)

- **Purpose:** omnibus tests of arm, visit and arm-by-visit with fixed, common occasions.
- **Key assumptions:** complete balanced data; normal errors; equal covariance matrices across groups; sphericity (equal variance of all pairwise differences), otherwise use GG/HF correction.
- **R example:**
  ```r
  summary(aov(sbp ~ arm * visit + Error(id / visit), data = lc))   # long, completers
  mlm <- lm(as.matrix(cc[, yv]) ~ arm, data = cc)                   # wide, completers
  idata <- data.frame(visit = factor(yv, levels = yv))
  anova(mlm, X = ~1, idata = idata, test = "Spherical")             # GG and HF
  mauchly.test(mlm, X = ~1, idata = idata)
  ```
- **Report:** number analysed vs randomised; interaction F, epsilon (GG or HF) and corrected p-value.
- **Common error:** reporting uncorrected p-values, or ignoring the participants removed by listwise deletion (in WALK, 122 of 360).

## Follow-up-only, change-score and baseline-adjusted ANCOVA (single follow-up)

- **Purpose:** estimate the treatment effect at one time point in a randomised trial.
- **Key assumptions:** randomisation; independent participants; linear baseline relationship with common slope across arms (ANCOVA); complete data at the follow-up.
- **R example:**
  ```r
  d12 <- wide |> filter(!is.na(sbp_m0), !is.na(sbp_m12))
  lm(sbp_m12 ~ arm, data = d12)                  # follow-up only
  lm(I(sbp_m12 - sbp_m0) ~ arm, data = d12)      # change score
  lm(sbp_m12 ~ arm + sbp_m0, data = d12)         # ANCOVA (preferred)
  ```
- **Report:** adjusted difference in means with 95% CI, n analysed, baseline adjustment pre-specified.
- **Common error:** defaulting to change scores; variance is proportional to 1 (follow-up), 2(1 - rho) (change), 1 - rho^2 (ANCOVA), so ANCOVA is never less precise.

## Separate tests at each visit

- **Purpose:** none as a primary analysis; at most descriptive.
- **Key assumptions:** independence within visit; but the set of tests ignores correlation, baseline and dropout.
- **R example:**
  ```r
  lapply(yv, \(v) summary(lm(reformulate("arm", v), data = wide)))
  ```
- **Report:** if needed, visit-specific contrasts from a single longitudinal model instead.
- **Common error:** inferring the "onset" of an effect from the first significant visit; 12 independent tests give 1 - 0.95^12 = 0.46 chance of at least one false positive.

## Decision points for method-selection diagrams

- Single pre-specified follow-up, randomised groups, little missing data: baseline-adjusted ANCOVA.
- Non-randomised groups with baseline differences: change score and ANCOVA answer different questions (Lord's paradox); state the causal question first.
- Several visits, any missing data, irregular actual times, or time-varying covariates: linear mixed model (Module 4), not RM-ANOVA.
- Complete, balanced data with fixed occasions and only omnibus tests needed: RM-ANOVA with Greenhouse-Geisser/Huynh-Feldt correction is acceptable, but an LMM gives estimates with CIs.
- Never: separate tests at each visit as the primary analysis.
