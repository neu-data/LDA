# Module 12 cheat-sheet input: planning, reporting and reproducibility

## Variance of a slope difference (balanced design)

- **Purpose:** predict the precision of the difference in mean slopes and the sample size before the study.
- **Key assumptions:** linear change; same times for everyone; complete data; independent residuals with constant variance; normal approximation.
- **R example:**
  ```r
  s_tt <- function(t) sum((t - mean(t))^2)
  se <- sqrt(2 * (tau1^2 + sigma^2 / s_tt(times)) / n_per_arm)
  n  <- 2 * (qnorm(0.975) + qnorm(0.9))^2 * (tau1^2 + sigma^2 / s_tt(times)) / delta^2
  ```
- **Report:** planning values (delta, tau1, sigma, times) and their sources, alpha, power, allowance for dropout.
- **Common error:** adding visits to compensate for too few participants (only more participants reduce tau1^2 / n).

## Correlation and a single follow-up

- **Purpose:** compare analyses of change at one time point.
- **Key relations:** relative variance follow-up only 1; change score 2(1 - rho); ANCOVA 1 - rho^2.
- **R example:**
  ```r
  rho <- cor(wide$sbp_m0, wide$sbp_m12, use = "complete.obs")
  c(change = 2 * (1 - rho), ancova = 1 - rho^2)
  ```
- **Report:** the correlation assumed and the analysis planned.
- **Common error:** using a change score when rho < 0.5 (less precise than follow-up only).

## Simulation-based power

- **Purpose:** power and sample size for realistic designs (dropout, irregular times, the planned model).
- **Key assumptions:** the data-generating model and planning values; seeds recorded; the simulated analysis is the planned analysis.
- **R example:**
  ```r
  pw <- power_two_arm(n_sims = 200, seed = 1, n_per_arm = 50, dropout = 0.1)
  pw                                   # power, mcse, n_sims
  power_two_arm(n_sims = 200, seed = 2, n_per_arm = 50, delta = 0)   # type I error
  ```
- **Report:** power with its Monte Carlo SE, n_sims, the data-generating model, and where the code is.
- **Common error:** reporting simulated power without its MCSE (MCSE = sqrt(p(1 - p) / n_sims); 1,600 trials for MCSE 0.01 at power 0.8).

## Statistical analysis plan (SAP)

- **Purpose:** fix the analysis before the data can influence it.
- **Contents:** Gamble et al. (2017) structure; ICH E9(R1) estimand (treatment, population, variable, intercurrent events with strategies, population-level summary); schedule and visit windows; full model syntax; responses to diagnostic and fitting problems; missing-data assumption and sensitivity analyses; software and versions.
- **Files:** `final-project/sap_template.md`; example `admin/templates/walk_sap_example.md`.
- **Common error:** writing or changing the SAP after seeing results without a dated record.

## Reporting checklist (short form)

- Schedule, numbers of participants and observations, missingness by arm and visit.
- Estimand (conditional or marginal).
- Mean model, random effects or covariance, distribution and link, estimation, df method, software versions.
- Diagnostics and fitting problems; MAR assumption and sensitivity analyses.
- Estimates with 95% CIs in outcome units; variance components; deviations from the SAP.

## Reproducible R project

- **Purpose:** anyone can rerun the analysis and get the same numbers.
- **Key practices:** R project + `here::here()`; no `setwd()`; numbered scripts writing to `outputs/`; data changed only in code; `sessionInfo()` saved; renv lockfile; Git with tagged release.
- **R example:**
  ```r
  walk <- readr::read_csv(here::here("data", "walk_long.csv"))
  writeLines(capture.output(sessionInfo()), here::here("outputs", "session_info.txt"))
  renv::init(); renv::snapshot(); renv::restore()   # start; after changes; elsewhere
  ```
- **Report:** code location and version; package versions.
- **Common error:** committing the renv library instead of `renv.lock`; absolute paths.

## Decision points

- Estimand is change at a fixed time: invest in precise baseline and final visits; intermediate visits for efficiency and dropout.
- Estimand is a linear slope: spread visits; ends are most informative.
- Change expected early or shape of change of interest: front-load visits.
- Formula available and design simple? Use it, then confirm the chosen n by simulation with dropout. Complex design? Simulate from the start.
- Choose n_sims from the MCSE you need; check type I error with delta = 0.
