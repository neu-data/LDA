## Cumulative-logit mixed model (repeated ordinal outcome)

- **Purpose:** model an ordered categorical outcome measured repeatedly (severity, Likert item, stage) without dichotomising; one cumulative odds ratio per covariate.
- **Key assumptions:** proportional odds (same coefficient at every cut-point); logistic latent error; normal random intercept; correct mean (for example linear in time on the logit scale); MAR missingness.
- **R example:**
  ```r
  library(ordinal)
  m <- clmm(severity_f ~ week * arm + (1 | id), data = clear, nAGQ = 7)
  summary(m)                                  # positive beta = more severe
  exp(12 * coef(m)["week:armActive"])         # cumulative OR over 12 weeks
  ```
- **Report:** cumulative odds ratio for the treatment-by-time effect with 95% CI; random-intercept SD; marginal predicted category probabilities by arm and time; result of a proportional odds check (nominal effects LRT with `clmm2(..., nominal = ~ ...)`).
- **Common error:** misreading the sign (`ordinal` uses theta_k minus eta, so positive coefficients mean higher categories), or reporting conditional odds ratios as population effects.

## Three-level linear mixed model (visits within participants within clinics)

- **Purpose:** account for clustering above the participant and partition the variance between clinic, participant and visit.
- **Key assumptions:** normal clinic and participant random effects independent of covariates; clinics a sample from a population; enough clusters to estimate the clinic variance (8 is few).
- **R example:**
  ```r
  m3 <- lmer(sbp ~ visit_f * arm + (1 + month | id) + (1 | clinic),
             data = walk, control = lmer_ctrl)
  VarCorr(m3)
  confint(m3, parm = "sd_(Intercept)|clinic", method = "profile", signames = FALSE)
  ```
- **Report:** variance shares and ICCs at each level; clinic SD with profile CI; treatment contrast with and without the clinic term.
- **Common error:** non-unique participant IDs across clinics (use `(1 | clinic:id)`), or ignoring clinic when treatment is assigned by clinic.

## Nonlinear mixed-effects model (asymptotic exponential)

- **Purpose:** describe a trajectory with a curve whose parameters have meaning (baseline, plateau change, time constant).
- **Key assumptions:** correct curve shape for everyone; normal random effects and residuals; good starting values; parameters identifiable from the visit schedule.
- **R example:**
  ```r
  m <- nlme(sbp ~ base - A * (1 - exp(-month / tau)), data = as.data.frame(walk),
            fixed = list(base ~ 1, A ~ arm - 1, tau ~ 1),
            random = list(id = pdDiag(base + A ~ 1)),
            start = c(base = 147, A = c(1.8, 7.6, 11), tau = 2))
  intervals(m, which = "fixed")
  ```
- **Report:** plateau change per arm and differences versus control with CIs; time constant with CI; random-effect SDs; check that estimates do not depend on starting values.
- **Common error:** wrong number or order of starting values (one per coefficient, in the order of the `fixed` list).

## Joint model for a biomarker and an event (JMbayes2)

- **Purpose:** relate the hazard of an event to the true current value (or slope) of an error-prone, intermittently measured biomarker; dynamic prediction.
- **Key assumptions:** correct longitudinal and survival submodels; correct functional form; conditional independence given random effects; non-informative censoring; MCMC convergence.
- **R example:**
  ```r
  lmeF <- lme(egfr ~ ns(years, knots = 2.5, Boundary.knots = c(0, 5)) + diabetes +
                diabetes:years + age10, random = ~ years | id, data = kid_long)
  coxF <- coxph(Surv(time, failure) ~ diabetes, data = kid_ev)
  jmF  <- jm(coxF, lmeF, time_var = "years", n_chains = 3L, n_iter = 25000L,
             n_burnin = 5000L, seed = 2026L)
  summary(jmF)                                  # value(egfr) = association
  ```
- **Report:** association parameter as HR per meaningful unit with 95% credible interval; submodel specifications; chains, iterations, burn-in, Rhat; comparison with naive time-dependent Cox if useful.
- **Common error:** using the last observed biomarker value in a time-dependent Cox model (attenuated), or using data-dependent spline bases without fixed knots.

## Marginal structural model with stabilised IPW (time-varying confounding)

- **Purpose:** estimate the effect of a treatment history when a time-varying confounder is affected by earlier treatment.
- **Key assumptions:** sequential exchangeability (no unmeasured confounding of each treatment decision), positivity, consistency, correctly specified treatment models.
- **R example:**
  ```r
  den1 <- glm(A1 ~ A0 + L0 + L1, binomial, dat); num1 <- glm(A1 ~ A0, binomial, dat)
  pr <- function(m, a) ifelse(a == 1, fitted(m), 1 - fitted(m))
  dat$sw <- sw0 * pr(num1, dat$A1) / pr(den1, dat$A1)   # sw0 from the time-0 models
  geeglm(Y ~ A0 + A1, data = dat, id = id, weights = sw, corstr = "independence")
  ```
- **Report:** weight models, weight distribution (mean, range, any truncation), MSM coefficients with robust CIs, the assumptions.
- **Common error:** adjusting for the time-varying confounder in an ordinary regression (blocks mediated effects and opens collider paths), or using model-based standard errors.

## Decision points for the method-selection diagrams

- Outcome is categorical with more than two levels: ordered? yes, check proportional odds, then cumulative-logit mixed model (or partial proportional odds if it fails); no, baseline-category (multinomial) logit model, involve a specialist.
- Participants grouped in clusters: treatment varies within clusters? yes, cluster as random or fixed effect (results similar); no (cluster-randomised), cluster random effect with small-sample df, involve a specialist if fewer than about 10 to 15 clusters.
- Trajectory follows a known curve and its parameters matter: nonlinear mixed model; otherwise splines in a linear mixed model (Module 9).
- Question links a repeatedly measured biomarker to an event, or an event truncates measurements: joint model; naive time-dependent Cox only as a comparison.
- Observational data with treatment that changes over time in response to a confounder affected by earlier treatment: g-methods (MSM with IPW, g-formula); always involve a specialist.
