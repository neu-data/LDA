# Module 8 cheat-sheet input: generalized linear mixed models

## Logistic mixed model (repeated binary outcome)

- **Purpose:** subject-specific (conditional) effects on the odds of a binary outcome, with between-participant variation.
- **Key assumptions:** logit linear in covariates given the random effects; normal random effects independent of covariates; independence given random effects; MAR dropout.
- **R example:**
  ```r
  m <- glmer(itch ~ week * arm + (1 | id), data = clear,
             family = binomial, nAGQ = 25)            # AGQ: one random intercept only
  m1 <- update(m, nAGQ = 1)                           # compare with Laplace
  fixef_table(m, exponentiate = TRUE)
  ```
- **Report:** estimation method (AGQ points or Laplace), conditional odds ratios with CI, random-intercept SD (or latent ICC = tau^2 / (tau^2 + pi^2/3)), plus marginal probabilities and risk differences.
- **Common error:** presenting GLMM odds ratios, or `emmeans(type = "response")` probabilities, as population-average quantities.

## Conditional vs marginal effects

- **Purpose:** convert or compare GLMM (conditional) and GEE (marginal) coefficients.
- **Key assumptions:** logit link, normal random intercept; approximation beta_M = beta_C / sqrt(1 + 0.346 tau^2).
- **R example:**
  ```r
  tau <- attr(VarCorr(m)$id, "stddev")
  fixef(m) / sqrt(1 + 0.346 * tau^2)                  # approximate marginal
  # exact: average plogis(eta + b) over b ~ N(0, tau^2) (Gauss-Hermite)
  ```
- **Report:** which kind of effect is reported; both if readers may compare with other studies.
- **Common error:** calling the GLMM-GEE difference "bias"; using one factor with random slopes. Log link with random intercept: slopes equal, intercept differs by tau^2/2.

## Population-averaged predictions with uncertainty

- **Purpose:** proportions, risk differences and risk ratios for the population from a GLMM.
- **Key assumptions:** approximate normality of (tau, beta) for the draw method; or use a parametric bootstrap.
- **R example:**
  ```r
  V <- 2 * solve(m@optinfo$derivs$Hessian)           # joint (theta, beta), nAGQ > 0
  d <- MASS::mvrnorm(4000, c(getME(m, "theta"), fixef(m)), V)
  # for each draw: integrate plogis over b, take arm difference, then quantiles
  ```
- **Report:** absolute probabilities by arm, risk difference and ratio with 95% intervals; method of integration and of interval.
- **Common error:** plugging b = 0 into the inverse link; emmeans `bias.adjust` (second-order) can be poor when tau is large (it overstated the CLEAR placebo week-12 proportion by about 0.07).

## Poisson and negative binomial GLMMs with exposure

- **Purpose:** rate ratios and expected counts for repeated counts with varying exposure.
- **Key assumptions:** log-linear rate given random effects; offset for exposure; NB: Var = mu + mu^2/theta.
- **R example:**
  ```r
  nb <- glmmTMB(migraine_days ~ post * arm + offset(log(days)) + (1 | id),
                data = diary, family = nbinom2)
  r <- simulateResiduals(nb, n = 1000); testDispersion(r); testZeroInflation(r)
  emmeans(nb, ~ arm | post, offset = log(28), type = "response",
          bias.adjust = TRUE, sigma = attr(VarCorr(nb)$cond$id, "stddev"))
  ```
- **Report:** rate ratio (ratio of rate ratios for a baseline-controlled design) with CI; expected counts per standard period (state conditional or population mean); dispersion checks.
- **Common error:** adding zero inflation because a Poisson model under-predicts zeros; test against NB, and only with a substantive reason.

## DHARMa residuals

- **Purpose:** simulation-based residual checks for any GLMM.
- **Key assumptions:** enough simulations (500-1000).
- **R example:**
  ```r
  r <- simulateResiduals(m, n = 1000, seed = 1)
  plot(r, quantreg = FALSE); testDispersion(r)
  rg <- recalculateResiduals(simulateResiduals(m, simulateREs = "unconditional"),
                             group = clear$id)        # grouped checks: unconditional
  ```
- **Report:** QQ plot and tests, with interpretation that does not rest on a single p-value.
- **Common error:** participant-level (grouped) tests with DHARMa 0.5.0's default conditional simulation, which reject correct models far too often.

## Decision points (for method-selection diagrams)

- Binary outcome, random intercept only: glmer with AGQ (nAGQ >= 10); more random effects: Laplace (glmer or glmmTMB).
- Counts: start with Poisson GLMM plus offset; overdispersion (DHARMa, Pearson ratio) leads to NB (nbinom2); zero inflation only if justified and better than NB.
- Population-average question with a GLMM: integrate over random effects (logit) or use bias.adjust (log link, exact).
