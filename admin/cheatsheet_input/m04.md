# Module 4 cheat-sheet input: linear mixed-effects models

## Random-intercept model

- **Purpose:** model repeated continuous measurements with a mean trajectory (fixed effects) and a participant-specific level (random intercept); gives the ICC.
- **Key assumptions:** linear mean as specified; $b_{0i} \sim N(0, \tau_0^2)$ and $\varepsilon_{ij} \sim N(0, \sigma^2)$, independent; implies compound symmetry (same correlation for every pair of visits, constant variance); MAR for missing data.
- **R example:**
  ```r
  m_ri <- lmer(sbp ~ month * arm + (1 | id), data = walk, control = lmer_ctrl)
  summary(m_ri); VarCorr(m_ri)
  icc_lmer(m_ri)
  ```
- **Report:** fixed effects with 95% CIs; $\hat\tau_0$, $\hat\sigma$ and ICC.
- **Common error:** using it when participants differ in their rate of change; the SEs of time-related effects are then too small.

## Random-slope model (linear-time reference model)

- **Purpose:** let each participant have their own intercept and slope; variance and correlation change with time.
- **Key assumptions:** $(b_{0i}, b_{1i}) \sim N(\mathbf{0}, G)$; independent residuals given the random effects; linear mean in time.
- **R example:**
  ```r
  m_lin <- lmer(sbp ~ month * arm + (1 + month | id), data = walk, control = lmer_ctrl)
  cov_to_cor(implied_cov_lmer(m_lin, c(0, 1, 3, 6, 9, 12)))
  anova(m_ri, m_lin, refit = FALSE)
  p_boundary_mixture(lr_test(m_ri, m_lin)$chisq, df_mix = c(1, 2))
  ```
- **Report:** slope differences with CIs; $\hat\tau_0$, $\hat\tau_1$, intercept-slope correlation, $\hat\sigma$.
- **Common error:** quoting a single ICC; testing the slope variance with a naive $\chi^2_2$ instead of the boundary mixture.

## Primary model: categorical time by arm, random slope on actual time

- **Purpose:** estimate the difference in mean change from baseline to a given visit without a shape assumption, using all participants (valid under MAR).
- **Key assumptions:** covariance correctly specified (random intercept and slope); MAR; scheduled visit adequate for the mean.
- **R example:**
  ```r
  m_cat <- lmer(sbp ~ visit_f * arm + (1 + month | id), data = walk, control = lmer_ctrl)
  emm <- emmeans(m_cat, ~ visit_f | arm)
  chg12 <- contrast(emm, list(chg12 = c(-1, 0, 0, 0, 0, 1)))
  summary(contrast(chg12, "trt.vs.ctrl", by = NULL, adjust = "none"), infer = TRUE)
  ```
- **Report:** difference in mean change at month 12 with 95% CI and p-value, the adjustment used, the number of participants, the MAR assumption. WALK: SP −5.38 (−8.17 to −2.58), EP −8.97 (−11.79 to −6.15) mmHg (unadjusted, Satterthwaite df).
- **Common error:** reading `armSP` (the baseline difference) as the treatment effect; leaving the default Dunnett adjustment of `trt.vs.ctrl` unreported.

## The same model in nlme

- **Purpose:** identical LMM fit; needed later for residual correlation structures (Module 5).
- **Key assumptions:** as above.
- **R example:**
  ```r
  m_lme <- lme(sbp ~ visit_f * arm, random = ~ 1 + month | id,
               data = walk, method = "REML")
  nlme::fixef(m_lme); VarCorr(m_lme)
  ```
- **Report:** as for `lmer`; state the degrees-of-freedom method (containment in `lme`, Satterthwaite in `lmerTest`).
- **Common error:** calling `fixef()` on an `lme` object after `setup.R` (which masks it with the `lme4` version); use `nlme::fixef()`.

## ML versus REML

- **Purpose:** REML gives less biased variance components (accounts for df used by fixed effects); ML allows likelihood comparisons of different fixed effects.
- **Key assumptions:** normal random effects and residuals.
- **R example:**
  ```r
  m_ml <- update(m_cat, REML = FALSE)
  anova(m_lin, m_cat)        # refits both by ML automatically
  ```
- **Report:** "REML for estimation; ML for likelihood-ratio tests of fixed effects; final model refitted by REML".
- **Common error:** comparing REML fits with different fixed effects (`refit = FALSE` or REML AIC).

## BLUPs and shrinkage

- **Purpose:** predict participant-specific random effects and trajectories.
- **Key assumptions:** model correct, including normal random effects.
- **R example:**
  ```r
  ranef(m_lin)$id                      # predicted deviations b_i
  coef(m_lin)$id                       # fixed + random (add arm-specific terms)
  coef(lme4::lmList(sbp ~ month | id, data = walk))   # no-pooling OLS lines
  ```
- **Report:** that individual predictions are shrunk toward the mean, more so with fewer observations; give prediction uncertainty when ranking individuals.
- **Common error:** using BLUPs as data in a second-stage analysis; expecting their SD to equal $\hat\tau$.

## Decision points for method-selection diagrams

- Continuous outcome, repeated over time, interest in mean change by group, missing visits or irregular times: linear mixed model (not RM-ANOVA).
- Few fixed visits and an estimand at one visit: categorical time for the mean, random slope on actual time for the covariance.
- Many or irregular times, or the rate of change is the question: continuous time; add curvature if needed (Module 9).
- Participants plausibly differ in rate of change: include a random slope (correlated with the intercept).
- Comparing fixed-effects structures: ML; comparing random-effects structures with the same fixed effects: REML; report the REML fit.
- Need residual correlation structures or heterogeneous variances: `nlme` (Module 5).
